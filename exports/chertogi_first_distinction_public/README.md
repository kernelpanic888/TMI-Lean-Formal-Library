## Claim boundary

The export presents a formal architecture candidate and an executable author
model. It does not establish consciousness, biological life, autonomous goals
or physical realization. Lean checks derivations inside stated formal
assumptions; it does not certify the interpretation of those assumptions as a
description of the world.

## Security boundary

The published surface is static and intentionally excludes Sites hosting
bindings, credentials, private/admin routes and write-capable network code.
External links are references only.
