# TLFL v0.5.1-alpha — Interface Foundations

## RU

Модульное расширение экспериментальной ветки Interface Foundations:
`RawOccurs`, явный `PlanckTouchBridge`, двусторонний контакт, минимальное
касание, двухосевое время, предсказательная граница, двухточечный внешний след,
семисимплициальное `d squared = 0` и поле целей с памятью.

Красная граница сохранена: это не доказательство физики, сознания, внешнего
спрашивающего, замысла или наддомена. Lean build и аудит аксиом для этого
alpha-релиза не запускались.

## EN

A modular expansion of the experimental Interface Foundations branch:
`RawOccurs`, an explicit `PlanckTouchBridge`, two-sided contact, minimum-touch
boundary, relational two-axis time, prediction boundary, two-point external
trace, semisimplicial `d squared = 0`, and a memory-bearing goal field.

The red boundary remains explicit: this is not proof of physics,
consciousness, an external questioner, design, or a supra-domain. No Lean build
or axiom audit was run for this alpha release.
