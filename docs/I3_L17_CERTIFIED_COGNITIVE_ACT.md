# I³-L17 — Certified Cognitive Act

## Status

`FORMAL CANDIDATE · EXECUTABLE CHECKER · NOT A CONSCIOUSNESS CLAIM`

L17 distinguishes a generated proposal from an admitted intellectual act. A
neural component may suggest an action, but it cannot authorize itself.

## Contract

An act is certified only when all gates close together:

1. the candidate binds an exact model digest and selector digest;
2. the declared proposal equals the recomputed neural proposal;
3. an independent selector keeps the action inside the action field;
4. the action forms an admitted two-axis tick;
5. the complete L16 independent hardware stack is admitted;
6. the transition has an exact trace, can be replayed, and exposes the prior
   state through a return operator.

If any gate fails, the executable returns `HOLD` and changes no state.

## Reading

The proposal is capability. The selector is permission. The two-axis tick is a
state transition. The trace makes the transition inspectable. Return makes its
origin recoverable. L16 prevents the software path from self-certifying its own
physical authority.

## Shoulders

- [ReAct](https://arxiv.org/abs/2210.03629) interleaves reasoning traces and
  actions. L17 adds fail-closed admission and exact state return.
- [Generative Agents](https://arxiv.org/abs/2304.03442) separates observation,
  memory, reflection, and planning. L17 treats these as architectural functions,
  not evidence of consciousness.
- [NIST AI RMF](https://www.nist.gov/itl/ai-risk-management-framework) motivates
  explicit trustworthiness and risk-management gates.
- [Butlin et al.](https://arxiv.org/abs/2308.08708) motivates the red boundary:
  architectural indicators do not by themselves settle consciousness.

## Red boundary

The checker certifies consistency of one bounded transition under supplied
policy and evidence. It does not prove consciousness, personhood, semantic
truth, real-world intelligence, or the honesty of unverified external inputs.
Without a real L16 PASS stack, L17 remains a formal and executable laboratory
contract.
