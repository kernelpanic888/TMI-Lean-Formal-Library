# TLFL v0.5.0-alpha

Тип релиза: экспериментальный слой оснований интерфейса.

Дата: 2026-07-30.

## Назначение

`v0.5.0-alpha` добавляет в TLFL отдельный формальный словарь для текущего
исследования интерфейсов. Стабильный агрегирующий импорт `TMI.Library` не
подменяется экспериментом. Новый слой подключается явно:

```lean
import TMI.InterfaceFoundationsAlpha
```

## Геометрия

```text
L <-> Sigma <-> R

слияние
| PlanckTouch
| допустимый коридор интерфейса
| HorizonTouch
| потеря связи
```

`PlanckTouch` читается как нижняя граница допустимого различимого контакта.
`HorizonTouch` читается как исключённая верхняя граница, к которой могут
приближаться допустимые состояния. Наличие нижней границы само по себе не
доказывает наличие верхней.

## Формальные записи

- `TwoSidedLanguage` задаёт стороны `L`, `R`, интерфейс `Sigma`, прямой и
  обратный контакты, эволюцию, обратное действие, память и энергию.
- `ThirdBodyRecord` отделяет критерий третьего тела от метафоры.
- `InterfaceCorridor` хранит две границы и допустимые состояния между ними.
- `HorizonApproach` задаёт абстрактную систему окрестностей для предельного,
  но исключённого касания.
- `TimeRelation` связывает физическую ось событий и внутреннюю ось записей.
- `PredictionGate` требует улучшения относительно базовой ошибки.
- `PrecisionBoundary` фиксирует `gap != measurement error`.

## Красная граница

Релиз не заявляет:

- эмпирическую физическую валидацию;
- обнаружение внешнего наддомена;
- доказательство сознания;
- тождество авторской геометрии с устройством Вселенной;
- существование `HorizonTouch` из одного факта `PlanckTouch`.

Статус модуля: `experimental`.

## Путь к v0.5.0

Перед стабильным релизом нужны:

1. сборка Lean;
2. аудит аксиом и импортов;
3. проверка совместимости с текущим toolchain;
4. отдельная модель нетривиального коридора;
5. связь с наблюдаемой или вычислимой предсказательной задачей;
6. синхронизация двуязычной документации.
